# Example Content Pack

This example is produced from `ExampleModAdapter` and is intentionally minimal.

The current content engines can produce:

- `/generated/polymer/` for the Polymer backend;
- `/generated/bedrock/` for the explicit Geyser/Bedrock backend.

The Bedrock output demonstrates:

- an explicit custom block mapping;
- a deterministic Bedrock resource-pack manifest;
- an asset-requirements manifest that explicitly reports missing Bedrock-native source assets;
- diagnostics showing partial interaction support and extension requirements.

No Java resource pack is converted automatically and no Create integration is included.
